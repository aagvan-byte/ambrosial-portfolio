# Ambrosial — сайт-портфолио

Личный сайт фриланс-разработчика: услуги, работы, процесс, контакты. Русская и английская версии.

## Что внутри

- Две языковые версии: `/` (русский) и `/en/` (английский) с переключателем
- Карточки проектов со скриншотами и ссылками на живые сайты, бота и код
- Нарисованный чат Telegram-бота — без скриншотов с личными данными
- Тёмная тема, адаптивная вёрстка, оптимизированные изображения

## Стек

[Astro](https://astro.build) · [Tailwind CSS](https://tailwindcss.com) · [Vercel](https://vercel.com)

## Запуск

```sh
npm install
npm run dev     # http://localhost:4321
npm run build
```

## Где что менять

- Все тексты на обоих языках — `src/i18n.ts`
- Проекты и ссылки — `src/components/Home.astro` (массив `projects`)
- Скриншоты — `src/assets/projects/`
- Цвета и шрифты — `src/styles/global.css`
